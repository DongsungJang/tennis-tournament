# 테니스 복식 대진표

코트 2면, 15:00~18:00(30분 × 6세션) 복식 대진표를 실력 균형에 맞춰 자동으로 짜 주는 웹 페이지입니다.
설치 없이 브라우저에서 바로 열립니다.

**바로 사용하기:** https://dongsungjang.github.io/tennis-tournament/

## 사용법
1. 왼쪽(휴대폰은 위쪽) 설정에서 인원을 10명 / 12명 / 14명 중에 고릅니다. 설정은 **상세** 화면에서 보입니다.
2. 참가자 이름을 **실력 순서대로** 입력합니다. 1번이 가장 잘 치는 사람이고, 순위 번호가 실력 점수로 쓰입니다.
3. **요약** 화면에서 시간대별 대진을 한눈에 보고, **복사** 버튼으로 단톡방에 붙여 넣을 수 있습니다.
4. 마음에 들지 않으면 **다른 조합으로**를 눌러 새로 편성합니다.

이름과 인원은 각자 브라우저에만 저장되며, 서버로 전송되지 않습니다.

## 편성 기준 (중요한 순)
- 한 코트 4명의 순위 합이 같게(예: 1+4 vs 2+3)
- 휴식 횟수를 고르게
- 3세션 연속 경기 피하기 (2연속까지 허용)
- 같은 편·상대 편으로 반복해서 만나는 것 줄이기
- 연속 휴식도 조금 피하기

시뮬레이티드 어닐링(온도 14 → 0.02, 20,000회 × 5회 재시작)으로 계산합니다.
10명은 1인당 휴식이 평균 1.2회뿐이라 3연속 경기를 완전히 피할 수 없습니다.
