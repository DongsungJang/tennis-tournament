# 테니스 복식 대진표

코트 2면, 15:00부터 30분 단위 세션으로 복식 대진표를 실력 균형에 맞춰 자동으로 짜 주는 웹 페이지입니다.
설치 없이 브라우저에서 바로 열립니다.

**바로 사용하기:** https://dongsungjang.github.io/tennis-tournament/

## 사용법
1. 왼쪽(휴대폰은 위쪽) 설정에서 인원(10~14명)을 고르고, 이름 옆 버튼으로 **사람마다 3게임/4게임**을 지정합니다. 설정은 **상세** 화면에서 보입니다.
   게임 수 합계 ÷ 8(코트 2면 × 4명)이 세션 수가 되고 15:00부터 30분 단위로 진행합니다. 합계가 8의 배수가 아니면 안내와 함께 **자동으로 맞추기** 버튼이 나옵니다.
   인원을 바꾸면 6세션 이하에서 가장 긴 편성으로 기본 지정됩니다(4게임은 위 순위부터).
2. 참가자 이름을 **실력 순서대로** 입력합니다. 1번이 가장 잘 치는 사람이고, 순위 번호가 실력 점수로 쓰입니다.
3. **요약** 화면에서 시간대별 대진을 한눈에 보고, **복사** 버튼으로 단톡방에 붙여 넣을 수 있습니다.
4. 마음에 들지 않으면 **다른 조합으로**를 눌러 새로 편성합니다.

이름과 인원은 각자 브라우저에만 저장되며, 서버로 전송되지 않습니다.

참가자 색은 실력대 3구간(상위 파랑 · 중위 초록 · 하위 주황)으로 나뉘고, 같은 구간 안에서는 명도만 조금씩 다릅니다. 인원에 맞춰 구간을 고르게 나눕니다(예: 12명이면 1~4 / 5~8 / 9~12).

## 편성 기준 (중요한 순)
- 한 코트 4명의 순위 합이 같게(예: 1+4 vs 2+3)
- 모두 첫 경기를 1~2세션 안에 (처음부터 1시간 기다리는 사람 없게)
- 휴식 횟수를 고르게
- 3세션 연속 경기 피하기 (2연속까지 허용)
- 같은 편·상대 편으로 반복해서 만나는 것 줄이기
- 연속 휴식도 조금 피하기

시뮬레이티드 어닐링(온도 14 → 0.02, 20,000회 × 5회 재시작)으로 계산합니다.
지정한 게임 수는 반드시 지킵니다. 그래서 한 세션 안에서 뛰는 사람과 쉬는 사람을 바꾸는 이동은 쓰지 않고, 두 세션의 휴식 인원을 맞바꾸는 이동으로 연속 경기 패턴을 조정합니다.
휴식 자리가 모자라 3연속을 피할 수 없는 지정(예: 10명 전원 4게임, 11명)이면, 가능한 출전 패턴을 모두 따져 계산한 최소 인원을 화면에 안내합니다.
